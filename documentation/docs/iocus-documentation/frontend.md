# FrontEnd

## Manual de usuario (administrador)

1. Ingresa tu nombre de usuario y contraseña para ingresar a la interfaz de la página web. 

2. Te encontrarás con cuatro secciones:
  - Mi cuenta. Se desplegarán datos del perfil de usuario, tales como nombre, foto, ubicación, introducción, y habilidades. 
  - Cursos. En esta sección se encontrarán funcionalidades para crear (deberás asignar un nombre y descripción) y administrar cursos. 
  - Ayuda. En este apartado encontrarás información relevante sobre los componentes y apartados del sitio web, en caso de que tener alguna duda sobre la plataforma. 
  - Cerrar sesión. Se desplegará la interfaz del paso uno, en la cual deberás volver a ingresar los datos de tu cuenta (nombre de usuario y contraseña) para volver a entrar al sitio web. 

  3. Al ingresar a un curso (en la sección "Administración de cursos"), tienes acceso a las siguientes secciones: 
    - Contenidos. En este apartado puedes subir archivos PDF, JPG, y PNG, para agregar contenido al presente curso (dicho contenido será visible para los estudiantes inscritos en dicho curso)
    - Quizzes. En este apartado podrás agregar quizzes al curso (especificando número de preguntas, y respuestas correctas). 
    - Calificaciones. En este apartado podrás revisar las calificaciones de tus estudiantes (las cuales se determinarán con base a las notas obtenidas en los quizzes). 
    - Regresar. En este apartado podrás regresar a la interfaz anterior, la cual contenía las secciones "Mi cuenta", "Cursos", "Ayuda", y "Cerrar sesión".
