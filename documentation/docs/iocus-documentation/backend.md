# Iniciando el Backend

Para poder iniciar con el backend es necesario instalar las dependencias necesarias en el caso de que estas no se hayan incluido en la descarga del sistema.

## Instalacion de dependencias

Las dependencias se hacen en la terminal del editor de codigo, en caso de usar VSCode se puede acceder a una nueva por medio de la pestaña `Terminal --> New Terminal`

Una vez en la terminal se recomienda confirmar que la direccion mostrada por la terminal es la misma en donde se tiene abierto el archivo de backend. Si esto ya ha sido verificado podemos pasar a la descarga e instalaciones de las dependencias justo como se muestra a continuacion.

```mdx title="C:\Users\node-mysql-api"
npm install express
npm install cors
npm install mysql2
npm install bcrypt
npm install express-rate-limit
npm install express-session
npm install path
```
