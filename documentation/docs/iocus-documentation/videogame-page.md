# Whirlpool's Game Quiz


## Acerca del Juego
El juego es un simulador de Concurso de Preguntas, donde dos tecnicos compiten por ver quien tiene mejor puntaje. El juego puede jugarse en solitario, con el segundo tecnico siendo controlado por un bot que tiene el 75% de sus preguntas bien, siendo este mas un elemento de ambientación que una mecanica real. Tambien se puede jugar de dos personas, donde ambos tratarán de ver quien tiene mayor puntuacion (intercalando turnos y añadiendo puntos por cada respuesta correcta).

![Preview 1](/img/ImagePrev1.png)

## Cuestionarios
El juego tiene previsto un sistema para poder elegir un cuestionario en formato Json. Sacará las preguntas aleatorizando su orden, y cuando todas las preguntas se hayan terminado, mostrará el puntaje de cada jugador.
